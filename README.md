# NotchTub - Official Website

This repository contains the source code for the official marketing website of **NotchTub**, a native macOS application that transforms the hardware notch into a dynamic, functional interface.

**Live Preview:** [https://srg-sphynx.github.io/NotchTubSite/](https://srg-sphynx.github.io/NotchTubSite/)

## Features
- **Interactive Notch Simulator:** Experience the dynamic notch behavior directly on the web.
- **Showcase:** Highlights Media integration, System Telemetry, and Utility features.
- **Tech Specs:** detailed system requirements and installation instructions.
- **Zero-Dependency:** Built with Vanilla HTML, Tailwind CSS (CDN), and JavaScript. No build step required for deployment.

## Development

1.  Clone the repository:
    ```bash
    git clone https://github.com/srg-sphynx/NotchTubSite.git
    cd NotchTubSite
    ```

2.  Open `index.html` in your browser or start a local server:
    ```bash
    # Python 3
    python3 -m http.server 8080
    
    # or just open the file
    open index.html
    ```

## Deployment

This site is designed to be hosted on **GitHub Pages**.

1.  Go to **Settings** > **Pages** in this repository.
2.  Under **Build and deployment**, select **Source** as `Deploy from a branch`.
3.  Select `main` (or `master`) branch and `/ (root)` folder.
4.  Save. The site will be live at `https://srg-sphynx.github.io/NotchTubSite/`.
